# @openai/nez-responses-api-proxy

<p align="center"><code>npm i -g @openai/nez-responses-api-proxy</code> to install <code>nez-responses-api-proxy</code></p>

This package distributes the prebuilt [Nez Responses API proxy binary](https://github.com/NezPifs/Nez-Code/tree/main/nez-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/nez-responses-api-proxy.js --help
```

Refer to [`nez-rs/responses-api-proxy/README.md`](https://github.com/NezPifs/Nez-Code/blob/main/nez-rs/responses-api-proxy/README.md) for detailed documentation.
